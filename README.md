# Робота з багатовимірними масивами (JavaScript)

У репозиторії реалізовано алгоритми для генерації та трансформації числових матриць.

## Опис реалізованих функцій

### Допоміжні методи
* `createMatrix(nRows, nCols, min, max)` — створює двовимірний масив випадкових цілих чисел у заданих межах.
* `displayMatrix(mat)` — друкує матрицю в консоль із форматуванням стовпців і рядків.

### Основна частина
1. **Зменшення значень на середнє рядка** (`minusRowAverages`) — знаходить середнє арифметичне елементів для кожного рядка та віднімає його від значень цього ж рядка.
2. **Зсув елементів по колу** (`shiftMatrix`) — виконує циклічний зсув матриці на $k$ позицій вправо та на $k$ вгору.
3. **Фільтрація за максимумом** (`dropMaxRowsAndCols`) — визначає максимальний елемент у матриці та прибирає всі рядки й стовпці, де він зустрічається.
4. **Транспонування й розворот (in-place)** (`rotateClockwise90`) — здійснює поворот матриці на 90 градусів за годинниковою стрілкою без створення нового масиву.
